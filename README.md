Udemy Clone (HTML + CSS)

A single-file, responsive recreation of the Udemy homepage UI,
built with plain HTML and CSS only (no JavaScript, no frameworks).

FILE
https://sathish-code-stack.github.io/udemy_clone — open directly in any browser.

INCLUDES
- Top promo bar
- Header with logo, search bar, categories button, nav links
- Hero section with gradient illustration
- Category pills
- Two course grids with cards (thumbnail, title, author, rating, price)
- "Trusted by companies" strip
- Value propositions section
- CTA banner
- Multi-column footer

NOTES
- Course thumbnails use CSS gradient placeholders instead of real
  images/logos.
- Fully responsive: adapts down to mobile (grid reflows from 5
  columns to 2, nav collapses, search bar wraps).
- Colors and layout are an original recreation for learning/demo
  purposes — not affiliated with or copied from Udemy's actual code.

CUSTOMIZE
- Colors: edit the CSS variables at the top of <style> (--purple,
  --black, etc.)
- Course content: edit the text inside each .course-card block.
